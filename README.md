# Disciplina EDA-LEDA

Repositório contendo estudos, implementações e exercícios da disciplina de **Estruturas de Dados e Algoritmos** e **Laboratório de Estruturas de Dados**.

## Organização do Repositório

### **[P1 - Algoritmos de Busca e Ordenação](./p1/README.md)**
- **Algoritmos de Busca:** Busca binária recursiva
- **Algoritmos de Ordenação:** QuickSort, MergeSort, CountingSort, RadixSort
- **Análise de Complexidade:** Comparação entre algoritmos O(n²) e O(n log n)
- **Problemas Práticos:** QuickSelect, Top-N elementos, dados quase ordenados

### **[P2 - Estruturas Lineares](./p2/README.md)**
- **Listas:** ArrayList e LinkedList com operações fundamentais
- **Pilhas e Filas:** Implementações clássicas e casos de uso
- **Estratégias de Cache:** FIFO, LRU, LFU com análise de desempenho
- **Tabelas Hash:** Encadeamento vs Endereçamento Aberto

### **[P3 - Estruturas Hierárquicas](./p3/README.md)**
- **Árvores Binárias:** BST com operações de busca, inserção e remoção
- **Árvores Balanceadas:** AVL com rotações automáticas
- **Heaps:** Min/Max heap e algoritmo HeapSort
- **B-Trees:** Estruturas para grandes volumes de dados

## Principais Tópicos Estudados

### **Fundamentos Algorítmicos (P1)**
- Análise de complexidade temporal e espacial
- Algoritmos de busca: linear vs binária
- Algoritmos de ordenação: comparação vs não-comparação
- Estratégias: divisão e conquista, força bruta

### **Estruturas Lineares (P2)**
- Listas dinâmicas vs arrays estáticos
- Pilhas (LIFO) e Filas (FIFO)
- Estratégias de cache e substituição de páginas
- Tabelas hash e resolução de colisões

### **Estruturas Hierárquicas (P3)**  
- Árvores binárias de busca (BST)
- Árvores auto-balanceadas (AVL, Red-Black)
- Heaps e filas de prioridade
- B-Trees para sistemas de arquivos

### **Algoritmos Avançados**
- Travessias (DFS: in/pre/post-order, BFS)
- Rotações e balanceamento em árvores
- Algoritmos de heap (sift-up, sift-down)
- Análise amortizada de operações
