# Disciplina EDA-LEDA

Repositório contendo estudos, implementações e exercícios da disciplina de **Estruturas de Dados e Algoritmos** e **Laboratório de Estruturas de Dados**.

## Principais Tópicos Estudados

### Estruturas Lineares
- Listas (Array e Linked)
- Pilhas e Filas
- Estratégias de Cache
- Tabelas Hash

### Estruturas Hierárquicas  
- Árvores Binárias de Busca (BST)
- Árvores AVL (auto-balanceadas)
- Árvores Red-Black
- Heaps (Min/Max)
- B-Trees

### Algoritmos
- Travessias (DFS: in/pre/post-order, BFS)
- Rotações em árvores
- Balanceamento automático
- Algoritmos de busca e ordenação
