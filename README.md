## Sobre o Repositório

Este repositório documenta minha trajetória nas disciplinas de **Estruturas de Dados e Algoritmos (EDA)** e **Laboratório de Estruturas de Dados (LEDA)** da **UFCG**.

Criei esse repositório com o foco principal de documentar minhas implementações e estudos das estruturas de dados.

---

## Organização e Implementações

O conteúdo está dividido em três estágios (P1, P2 e P3), cobrindo desde algoritmos básicos até estruturas hierárquicas complexas.

### [P1 - Algoritmos de Busca e Ordenação](./p1/README.md)
O foco inicial foi entender a eficiência de algoritmos (`Big O`).
* **Ordenação:** Implementação e análise de *QuickSort*, *MergeSort*, *CountingSort* e *RadixSort*.
* **Busca:** Busca Binária recursiva e interativa.
* **Análise:** Comparação prática entre algoritmos quadráticos $O(n^2)$ e logarítmicos $O(n \log n)$.
* **Aplicações:** Problemas como *QuickSelect* e seleção de Top-N elementos.

### [P2 - Estruturas Lineares](./p2/README.md)
Desenvolvimento de estruturas de armazenamento sequencial e acesso direto.
* **Listas:** Implementação manual de *ArrayList* e *LinkedList* (Simples e Duplamente encadeada).
* **Pilhas e Filas:** Estruturas LIFO e FIFO aplicadas a problemas reais.
* **Tabelas Hash:** Tratamento de colisões via encadeamento (chaining) e endereçamento aberto.
* **Cache:** Implementação de estratégias de substituição como LRU (Least Recently Used) e LFU.

### [P3 - Estruturas Hierárquicas](./p3/README.md)
Estudo de estruturas não-lineares para grandes volumes de dados.
* **Árvores Binárias (BST):** Algoritmos de travessia (DFS/BFS), inserção e remoção.
* **Árvores Balanceadas (AVL):** Implementação de rotações automáticas para manter a altura logarítmica.
* **Heaps:** Construção de Min-Heap e Max-Heap para filas de prioridade e *HeapSort*.
* **B-Trees:** Introdução a estruturas otimizadas para sistemas de arquivos e bancos de dados.

## 🇺🇸 English Version

### Data Structures and Algorithms (UFCG)

This repository contains implementations and study notes from the **Data Structures and Algorithms** courses at **UFCG**. The goal is to understand the inner workings of fundamental structures by implementing them from scratch in Java.

**Repository Structure:**

* **[P1 - Search & Sort](./p1/README.md):** Analysis of sorting algorithms (QuickSort, MergeSort) and binary search implementation. Focus on Big-O complexity.
* **[P2 - Linear Structures](./p2/README.md):** Custom implementation of Lists (Array/Linked), Stacks, Queues, and Hash Tables handling collisions.
* **[P3 - Hierarchical Structures](./p3/README.md):** Advanced trees including BSTs, balanced AVL Trees, and Heaps (Priority Queues).
