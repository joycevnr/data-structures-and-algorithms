- `SolutionInvertePilhaIndex.java` - Inversão com controle de índice

## Destaques por Categoria

### **Mais Importantes para Estudo**
1. **`RotacaoAVL.java`** - Sistema completo de rotações
2. **`BFSDireita.java`** - Variação interessante de BFS
3. **`VerificadorAVL.java`** - Validação de propriedades
4. **`AlturaBST.java`** - Algoritmo fundamental

### **Algoritmos Únicos**
- **BFS Direita**: Travessia em largura priorizando lado direito
- **Inverter Pilha**: Algoritmos para manipulação de pilhas
- **Árvores Similares**: Comparação estrutural de árvores

### **Análise de Complexidade**
- Maioria dos algoritmos: **O(n)** para travessias
- Operações de busca: **O(log n)** em árvores balanceadas
- Verificações: **O(n)** para análise completa
